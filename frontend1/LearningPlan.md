# React Learning Plan

## Goal
My goal is to build a frontend application using React that connects to a REST API with authentication. By the end of week 5, I want to create a working frontend for a project collaboration app where users can log in, view projects, and interact with backend data.

I already know some basic JavaScript, HTML, CSS, Git, and API concepts, but I am still new to React. I can spend about 8–10 hours per week learning and practicing.
